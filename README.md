## The pitch

> A marketplace selling pre-written 'I need more context' replies to lazy AI agents, charging $0.02 per deflection.

One sentence, 113 characters. Absurdly specific (lazy AI agents buying canned stall tactics) yet commercially believable: a per-deflection micro-payment is exactly how such a market would price it.

## How it works

`main.ts` (Node, no dependencies) validates the pitch against the kit gate — 1 to 200 characters, not only whitespace, exactly one sentence — then writes it to `/output/entry.txt`. It never removes the output directory itself, only creates it when missing.
